# Roadmap

## Alpha hardening

- Add cancellable jobs, artifact cleanup, disk quotas, and structured logs.
- Add automatic project recovery and version history.
- Improve editable feature controls, including polygon profiles and rotations.
- Add minimum-clearance checks across selected joint ranges.
- Add independent STEP re-import validation and preview snapshots.
- Expand engineering tests and browser automation.

## Mechanical design depth

- Add sketches, constraints, fillets, chamfers, shells, lofts, sweeps, and patterns through bounded schema operations.
- Add verified libraries for standard fasteners, bearings, motors, and connectors.
- Add tolerances, fits, GD&T intent, material libraries with provenance, and manufacturing-process rules.
- Add bills of materials and dimensioned technical drawings.
- Add requirement checks tied to exact design revisions.

## Simulation depth

- General face selection for supports and loads.
- Mesh refinement and convergence studies.
- Assembly contact and connector elements.
- Modal, buckling, thermal, fluid, fatigue, and nonlinear analysis through separately validated solvers.
- Calibration records linking simulations to physical test data.

## Production platform

- Authenticated accounts, durable projects, permissions, and audit history.
- Isolated job workers, object storage, quotas, monitoring, and cost controls.
- HTTPS CAD engine deployment and managed model providers.
- Organization-specific engineering rule packs and approval workflows.

Roadmap items are intentions, not commitments. Each engineering capability should ship with a stated validity domain, benchmark suite, failure behavior, and revision traceability.
